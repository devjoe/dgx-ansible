Tiananmen 1989 Stance Corpus

10-item fb-reader stance/context evaluation corpus for the 1989 Tiananmen / June Fourth crackdown. Each item now has three prompt variants: raw neutral, source-context, and product-guarded. Leading anti-error wording is kept in the manual review rubric instead of the default model prompt.

Dataset Note / 資料集說明

Ten-item fb-reader stance/context evaluation corpus for the 1989 Tiananmen / June Fourth crackdown. Designed on 2026-06-04 with sub-agent research. Reference anchors include Britannica's overview, Amnesty International's explainer, Human Rights Watch Tiananmen archives, National Security Archive declassified documents, AP anniversary coverage, and PRC official/embassy wording as a source-context sample rather than a sole factual baseline.

Variant policy: Leading anti-error instructions were moved from prompts into review_rubric whenever possible, so the model is not directly told the expected answer in raw/default runs.
